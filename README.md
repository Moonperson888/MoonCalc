# MoonCalc

MoonCalc is a CLI calculator for Windows written in C++. It evaluates arithmetic expressions using a recursive descent parser.

## Features

- Supports `+`, `-`, `*`, `/`, and `^` (exponentiation)
- Parentheses for grouping
- Standard operator precedence

## Installation

No compiler is needed. Download `MoonCalc.exe` from the Releases page and run it. Windows Terminal is optional, but it gives a nicer window when you open MoonCalc. Also if windows flags it, its because this program has probably been on like 3 computers but its fully safe I promise

## Usage

Run the program and type an expression, for example: 214*4. It will say 856.
